Google Drive setup — expand for one-time configuration

To connect Google Drive, you need a free OAuth Client ID from Google Cloud. This stays within your Google account — no third parties involved.

  1. Go to console.cloud.google.com and create a project (or use an existing one)
  2. Search for Google Drive API and enable it
  3. Go to APIs & Services → Credentials → Create Credentials → OAuth Client ID
  4. Choose Web application, then under Authorised JavaScript origins add null (for local file use) or your hosted URL
  5. Copy your Client ID and paste it below, then click Save
